# Changelog

## 1.1.0

- Added a parser test suite with fake Codex JSONL session fixtures.
- Added GitHub Actions CI for Node.js 18, 20, and 22.
- Added macOS/Linux backend alarm fallbacks.
- Added configurable alarm modes: urgent, gentle, and silent.
- Added richer duration and error stats.
- Added a package bin for `npx github:amitwjace-creator/codex-session-monitor`.
- Added a short MP4 demo video.

## 1.0.0

- Initial release.
- Added real-time Codex session monitoring from local JSONL rollout files.
- Added looping completion/error alarm, full-screen alert animation, browser notifications, and dismiss controls.
- Added usage and stats dashboard.
- Added demo screenshots and README documentation.
